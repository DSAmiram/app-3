# اپ جدول کوددهی گابریست

اپ اندروید با PDF داخلی (`gabrist.pdf`)، آیکون اختصاصی و جست‌وجوی متن که با تپ روی نتیجه به همون صفحه می‌پره.

## ساخت APK
1. پوشه رو با Android Studio باز کن (Open).
2. صبر کن Gradle Sync تموم بشه (نیاز به اینترنت داره).
3. از منو: Build > Build Bundle(s)/APK(s) > Build APK(s).
4. فایل APK در مسیر app/build/outputs/apk/debug/ ساخته می‌شه؛ نصبش کن.
